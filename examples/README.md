# Синтетические документы для демонстрации

Все компании, операции, суммы и контрагенты в этой папке вымышлены. Файлы предназначены только для локальной демонстрации загрузки документов в кредитную заявку.

## Банковские выписки

- `bank-statements/stable_business_6m.csv` — стабильные поступления за шесть месяцев, несколько покупателей и регулярные налоговые платежи.
- `bank-statements/seasonal_business_12m.csv` — двенадцать месяцев с выраженным сезонным ростом и спадом.
- `bank-statements/concentrated_revenue_6m.csv` — большая часть выручки поступает от одного покупателя; встречается отрицательный остаток.

Формат: `дата;сумма;направление;остаток;назначение;контрагент`. Для входящих операций сумма положительная, для исходящих — отрицательная.

## Финансовые документы

- `financial-documents/usn_declaration_stable_12m.csv` — декларация УСН устойчивого бизнеса за 12 месяцев.
- `financial-documents/accounting_report_growth_6m.csv` — отчётность растущего бизнеса за 6 месяцев.
- `financial-documents/tax_declaration_low_margin_12m.csv` — декларация бизнеса с низкой чистой маржой.

Формат: `период_месяцев;выручка_за_период;чистая_прибыль_за_период`. Интерфейс сам пересчитает значения в среднем за месяц.
