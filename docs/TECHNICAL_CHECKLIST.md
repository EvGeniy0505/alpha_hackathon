  и отклоняемые поля реквизитов внутри анкеты.

  что отдельной таблицы пользователей нет.

## Перед отправкой

Укажите окончательный commit hash из git rev-parse HEAD или опубликованный тег.
Для публичного репозитория отдельный доступ аккаунту alfa-hack-2026 не нужен.
Облачная публикация дополнительная; конфигурация готова в render.yaml,
но публичный сервис в аккаунте владельца пока не создавался.
Бесплатный Render теряет локальную SQLite при перезапуске/засыпании,
поэтому основная воспроизводимая версия использует Docker Compose и постоянный том.
Инструкции — docs/DEPLOYMENT.md.

Текущие ограничения MVP: один экземпляр приложения с SQLite,
демонстрационная аутентификация, локальные симуляторы ФНС/БКИ,
имитация подписания и выдачи. Эти упрощения явно описаны и не требуют
платных или корпоративных систем.
